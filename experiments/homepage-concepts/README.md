# Homepage Concepts

Side-project prototype for three candidate Photos By Elie main pages.

- `01 Atlas`: bright editorial destination grid with quick country routes.
- `02 Darkroom`: cinematic full-bleed hero with animated film rail.
- `03 Desk`: warmer collection/workbench layout with search-first browsing.
- `04 Best Mix`: literal current home with only the Nerja cave backdrop override.

Open `index.html` through the repo's local server:

```text
http://localhost:8000/experiments/homepage-concepts/
```

These files are not linked from the production homepage and do not change the visible site version.

`best-mix.html` uses an ignored local backdrop copy at `tmp/homepage-concepts/nerja-original-bg.jpg`, sourced from Saturn:

```text
/Volumes/Saturn/Pictures/LR/Apple Photo Albums/2026 Nerja, the Caves/IMG_3507.JPG
```
