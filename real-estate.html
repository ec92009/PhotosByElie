How project outputs work

  1. Select photos or videos with the checkbox in the lower-right corner of each preview.
  2. Edit the media title if the PDF or slideshow should use a different caption.
  3. Choose one or more apartment projects below the title. Shared media can belong to multiple projects.
  4. Choose A4 or Letter paper size, then download one PDF per project. Selected videos appear in PDFs as stills from 10% into the clip.
  5. Set the slideshow seconds for still photos; selected videos keep their full original duration in the slideshow plan.
  6. The browser can save or share project PDFs, slideshow plans, and selection tables.
  7. Use originals ZIP when selected final source media should be saved or shared as one file.
  8. Share a selection table to Notes or another app, open it in the browser for review, or load it later to continue from the same media/title/project choices.
